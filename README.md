# Aplikasi CRUD Data Mahasiswa
**Mata Kuliah / Ujian Praktik Web**

Proyek ini adalah aplikasi web berbasis CRUD sederhana yang dibangun menggunakan HTML, CSS, JavaScript, PHP Native, dan MySQL. 

- **Tema Proyek:** Data Mahasiswa
- **Pembuat:** Mochamad Putra Nurhadi
- **Jurusan:** Teknik Informatika
- **Instansi:** Universitas Muhammadiyah Sukabumi

## Fitur
1. Menampilkan data mahasiswa dengan thumbnail foto.
2. Form berfungsi ganda untuk Create & Update (Pre-filled data).
3. Upload foto dengan penggantian nama file otomatis (`uniqid()`) dan pembatasan ukuran maksimal 2MB.
4. Validasi JavaScript untuk input kosong, format file, batas ukuran file, dan konfirmasi hapus.
