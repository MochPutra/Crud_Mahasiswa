## Fitur
1. Menampilkan data mahasiswa dengan thumbnail foto.
2. Form berfungsi ganda untuk Create & Update (Pre-filled data).
3. Upload foto dengan penggantian nama file otomatis (`uniqid()`) dan pembatasan ukuran maksimal 2MB.
4. Validasi JavaScript untuk input kosong, format file, batas ukuran file, dan konfirmasi hapus.
